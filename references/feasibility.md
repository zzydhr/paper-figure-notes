# 可行性验证记录（2026-07-26）

在写实现计划前，用真实论文 PDF 验证了最容易翻车的一步：**figure 区域切割**。

测试样本（两种排版各一篇）：

| 样本 | 排版 | 特点 |
|------|------|------|
| `2025.acl-long.239.pdf` | ACL 双栏 LaTeX，24 页，11 图 19 表 | 图多为**纯矢量**绘制 |
| `PMC13254047.pdf`（Scientific Reports，格拉母瘤 DMC-GF 铁死亡） | Nature 系单栏，14 页，5 图 | 图为**整张大位图**，含跨页图 |

## 结论速览

| 环节 | 结论 | 证据 |
|------|------|------|
| Caption 定位 | ✅ 可靠 | ACL **11/11 图 + 19/19 表全命中**；SciRep 5/5 图命中（含 `Fig. N (continued)`） |
| Figure 切割（LaTeX 矢量） | ✅ 可靠 | 矢量/位图/混合图均切出完整紧致图像 |
| Figure 切割（期刊位图） | ✅ 更简单 | 直接用 image rect 即得精确 bbox，无页眉无 caption 溢出 |
| 一页多图分离 | ✅ 可靠 | "上方 caption 作天花板" 规则解决图与图互相吞并 |
| Table 区域切割 | ❌ 几何法失败 | 见 §3「表格必须换路线」 |
| PyMuPDF `find_tables()` | ❌ 不可用 | 三线表无竖线，Table 1 检出 0 个，Table 2 解析成 3×2 乱码 |

> ⚠️ **计划假设被推翻（好消息）**：原计划把「生物医学期刊复杂拼版大图」列为最高风险。
> 实测相反——期刊排版把整张多面板图存成**单个位图**，比 LaTeX 论文的矢量图**更容易切**。
> 真正的难点转移到了**跨页图合并**与**图题跨页配对**，见 §5。

## 关键技术决策（已被证据支持）

### 1. 切图必须用「裁剪后渲染页面」，不能用「抽取内嵌图像对象」

这是最重要的一条。测试论文里 **Figure 1、3、4、5、6、7、8 全部是 0 个内嵌位图**，
纯由 8~50 个矢量绘图指令构成。若走常见的 `page.get_images()` 抽 XObject 路线，
这些图会**全部丢失**；而 Figure 2 这类混合图会被切成 11 个碎片。

正确做法：算出图形区域 bbox 后用 `page.get_pixmap(clip=bbox, dpi=200)` 渲染。
矢量图、位图、拼贴图、坐标轴文字、panel 标号 (a)/(b) 一次性全部保留。

实测 200 DPI 已足够 VLM 读清坐标轴刻度和图例小字；300 DPI 留给密集热图/免疫印迹。

### 2. Figure bbox 算法（已验证）

```
对每个 figure caption：
  1. 判定 caption 所属栏（按文本块 x 中心聚类出 1 栏或 2 栏）
  2. 天花板 ceiling = 同栏内、位于本 caption 上方的最近一个 caption 的底边
     （无则取页面顶边）—— 这一步是一页多图不互相吞并的关键
  3. 候选图形 = 所有 image rect + drawing rect，满足：
        r.y1 <= caption.y0     （在 caption 上方）
     且 r.y0 >= ceiling         （不越过上一个图）
     且 与本栏横向重叠 > 25%    （不跨栏误吸）
  4. bbox = 候选并集，四周留白 4pt，与页面矩形取交
```

实测 page 7（Figure 5 + Figure 6 + Table 3 + Table 4 同页）和 page 8（Figure 7 + 8 双栏并列）
均切割正确；Figure 6 的 ceiling 规则生效（ceiling=316，精确避开了上方内容）。

⚠️ 注意 caption 位置约定因期刊而异：**图题在下、表题在上**是主流，但需按刊适配。

### 3. 表格必须换路线（几何法已证伪）

失败现象：Table 2 用「caption 向下扫文本块」切出来的是**一整段正文**，完全不是表格。
根因是 ACL 表题在表**上方**，且三线表与正文在几何上无法区分。

改用**双通道**方案：
- **通道 A（图像）**：裁剪本栏内 [上一个 caption 底边, 下一个 caption 顶边] 的整条带状区域渲染成图。
  这个带一定包含表格本体，宁可多切一点空白，也不会切错内容。VLM 读三线表图像很稳。
- **通道 B（文本）**：同区域用 `page.get_text("words")` 按 y 聚行、按 x 聚列还原成文本网格。
  用途是给 VLM 提供**精确数字串**做交叉校验，防止读图时看错小数点。

不依赖任何表格解析库，避免 `find_tables()` 那类脆弱依赖。

### 4. 不需要引入版面检测模型

纯几何 + PyMuPDF 在双栏 LaTeX 论文上已达到接近 100% 的准确率，零额外依赖、零 GPU。
`docling` / `DocLayout-YOLO` 仅在以下情况才考虑作为可选后端：
- 生物医学期刊的复杂拼版大图（Nature/Cell 系跨栏图）经实测失败
- 扫描版无文本层 PDF（此时还需 OCR）

**已验证**：Scientific Reports（Nature 系）单栏排版同样无需版面模型，见 §5。

## 5. 期刊排版（生物医学）路线：更简单，但有跨页问题

`PMC13254047.pdf` 的页面构成实测：

```
 页  正文字符  位图数  图占页面积   性质
  4     2786      1     26.2%     图 + 部分正文
  6      298      1     43.4%     整页图（Fig 2 主体）
  8      148      1     38.3%     整页图（Fig 2 continued）
 10      149      1     30.4%     整页图（Fig 3 continued）
 13     7026      0      0.0%     纯正文（参考文献）
```

特征与对策：

1. **每张图 = 单个位图**。`page.get_image_rects()` 直接给出精确 bbox，
   无需矢量聚类、无需分栏、无需 ceiling 规则。实测 page 6 切出的
   火山图 + GO 富集 + KEGG 富集三面板图完整无损，**无页眉、无图题溢入**。

2. **图题在图下方，且常溢出到下一页**。Fig 2 主体在 page 6，图题却起始于 page 7 顶部（y=48）。
   若沿用「图在 caption 上方」的假设，会切出一条 32pt 的废条。

3. **跨页图**。`Fig. N (continued)` 是独立 caption，实为同一张图的续页。
   必须按图号合并，输出为同一 figure 的多张切图（不要拼接成一张巨图，
   VLM 分开读反而更准）。

4. **整页图页判定**：正文字符 < 600 且图占比 > 20% ⇒ 该页主体是图。

### 排版自适应分派（最终算法）

两条路线用一个规则分派，同时覆盖两个领域：

```
若 页面存在单个位图且面积 ≥ 10% 页面：
    → 期刊排版路线：直接取 image rect 作 bbox（生物医学、Nature/MDPI/Frontiers 系）
否则：
    → LaTeX 排版路线：矢量图形聚类 + 分栏 + ceiling 规则（ACL/NeurIPS/arXiv 系）
```

caption 与图的配对独立于切割，按「同页就近 → 上一页尾部 → 下一页顶部」三级回退，
并用图号一致性校验。

## 6. Nature 系正刊排版（2026-07-26 实战暴露）

用户拿真实论文试跑（*Nature Genetics*，44 页，正文 8 图 + Extended Data 10 图），
一次暴露出四个缺陷。**它们都不是边角情况，Nature 系期刊都这么排版**——
之前两篇样本恰好没有 Extended Data 章节，所以全都漏掉了。

### 缺陷一：`Extended Data Fig. N` 被并进正文 `Fig. N`

图题正则里 `extended data|supplementary` 前缀虽然匹配得上，却是**非捕获**的、随即丢弃，
于是两者身份完全相同、按图号合并。应有 18 张图只出了 10 张，切图张冠李戴。

**对策**：序列身份（`CaptionAnchor.series` / `FigureAsset.series`）贯穿全链路——
`figure_id`、切图文件名、合并键、图号顺序校验都必须带上它。**图号只在序列内唯一。**

### 缺陷二：跨栏大图被按单栏裁切

Nature 用「整幅大图 + 单栏图题」：图题只占左栏（实测 x=40–292），
图却横跨两栏（x=55–561）。按图题所在栏去裁，右半张图直接没了。

**对策**：`_effective_column()`——图形明显越出本栏时改用整幅内容宽度。
但**必须**排除真·双栏并排两图（ACL 的 Fig.7 左 / Fig.8 右）：
要求另一栏在同一纵向区间内没有别的图题。

### 缺陷三：向上聚类被行间距截断

原先遇到 >`CLUSTER_GAP`(34pt) 的垂直断裂就停，这在 LaTeX 正文里是为了不吸进数学公式；
但 Nature 多联图的**行间距**经常超过它，于是只切出贴着图题的那一行 panel
（实测 Fig.1 八个子图只剩队列表一个，覆盖 11%，**还报 high 置信度**）。

**对策**：改判「缝隙里有什么」而不是「缝隙有多宽」——从最贴近图题的簇往上逐个合并，
只在**簇间缝隙**出现正文时才停。只看缝隙同时避免了把子图自身的宽文本
（相关系数标注、表格行、panel 列标题）误判成正文。

另加覆盖率兜底：切图占候选图形不足 60% 时**一律不许报 high**。
高置信度切错比低置信度切错危险得多——下游会把残图当完整图去读。

### 缺陷四：图题页没有图形时切出正文

Fig.2/4/5/7 的图题排在**纯文字页**上（p8 有 9017 字符、零图形），图在相邻页。
跨页配对原先要求邻页通过 `is_figure_page()`，这些页不达标，于是降级到在文字页上
切一条带——**切出来的是一整段讨论正文，还标着 medium 置信度**。

**对策**：图题页自身没有图形时放宽邻页判定（有实质图形即可）、搜索扩到 ±3 页、
一页只供一张图（同页两条图题必须落到不同页）。方向由图题位置决定：
贴着页顶 = 上一页那张图的续尾（Scientific Reports 排法），否则图在图题之后（Nature 排法）。
降级分支本身也加了守卫：页面完全没有图形时如实标 LOW 并写明「切图很可能是正文」。

### 排版对照

| | ACL / arXiv | Scientific Reports | Nature 正刊 |
|---|---|---|---|
| 图形 | 纯矢量为主 | 单张大位图 | 混合，常整幅跨栏 |
| 图题位置 | 图下方同栏 | 图下方，常溢到下一页 | 正文页内，**图另起一页** |
| 子图标号 | `(a)` / 无 | `(A)` `(B)` | `a,` `b,` `a,b,`（小写+逗号） |
| Extended Data | 无 | 无 | 有，**独立图号序列** |
| 主要风险 | 数学公式被吸入 | 跨页图合并 | 跨栏、跨页、序列混淆 |

## 7. 附带验证：paper-search CLI 可接入

- `paper-search search --sources europepmc` 可拿到 OA 论文的直链 `pdf_url` ✅
- `paper-search download --platform pmc` 对 PMC viewer 失败（需浏览器 proof-of-work）❌
- 结论：P5 打通检索链路时，**走 Europe PMC 的 `pdf_url` 直下**，不要用 PMC 原生下载

## 兜底策略

任一步几何计算失败时，逐级降级，保证永远有可用产出：

1. 图形候选为空 → 裁剪本栏 [ceiling, caption.y0] 整条带
2. 带高度异常（< 40pt 或 > 页高 80%）→ 渲染整页
3. 整页也标记 `bbox_confidence: low`，交给下游模型自行判断，并在报告中提示人工复核
